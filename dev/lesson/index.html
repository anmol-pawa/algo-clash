S1 · Your first program

main and includes

A C++ program starts at main. Everything else you use, from cout to vector, is declared in a header that you pull in with #include.

main returns an int status; falling off the end of main returns 0 for you, so most programs omit return 0.

Idiom: Name your headersInclude the header for every library name you use (<vector>, <string>, <algorithm>). A name that compiles on your machine only because another header happened to include it will fail somewhere else.

using namespace std; lets you write cout instead of std::cout. That is fine inside a single .cpp file and common in interview code, but never put it in a header: every file that includes the header inherits it, and names start to collide.

InterviewInterviewers do not mind using namespace std; in a coding round. They do notice a missing #include <algorithm> or a guessed signature, so state the headers you need out loud.
