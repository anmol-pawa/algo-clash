# Algo Clash

A handheld-style creature RPG that teaches data structures and algorithms in C++. Play: https://anmol-pawa.github.io/algo-clash/

```
npm ci
npm run dev          # http://localhost:3000
npm run lint && npm run typecheck && npm test && npm run build && npm run build:pages
```

Design docs live in `docs/`; the build plan is `ROADMAP.md`; see `CLAUDE.md` for the routine protocol.
