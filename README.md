# Algo Clash

A handheld-style creature RPG that teaches data structures and algorithms in C++, up to FAANG interview level. Recognise the pattern, pick the structure, write the C++; an in-browser compiler judges it.

Play: https://anmol-pawa.github.io/algo-clash/

```bash
npm ci
npm run dev          # http://localhost:3000
npm run lint && npm run typecheck && npm test && npm run build && npm run build:pages
```

Design docs: `docs/GAME_DESIGN.md`, `docs/CURRICULUM.md`, `docs/ARCHITECTURE.md`. Roadmap: `ROADMAP.md`. Contributor/routine rules: `CLAUDE.md`.
